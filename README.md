## 🚀📧 EXPORT Automation

> *AI-powered buyer lead management & email outreach automation.*

A smart Flask-based system for managing export buyers, classifying emails, and automating outreach.

## ✨ Features

- 👥 Buyer lead management
- 📥 CSV lead import
- 🤖 Gemini AI email classification
- 📧 Individual & bulk email sending
- ⭐ Lead scoring
- ✅ Contacted tracking
- 📊 Campaign reports
- 🧪 Demo mode without API keys

## 🔄 Workflow

```text
🔎 Leads → 📥 Validation → 🤖 AI Classification → 📧 Outreach → 📊 Reports
````

## 🛠️ Tech Stack

**Python • Flask • HTML/CSS • Pandas • Gemini AI • Gmail SMTP • GitHub • Render**

## 💻 Run Locally


### 🪟 Windows

1. Clone the repository:
````markdown
```bash
git clone https://github.com/rashiuwu/export-automation.git
````

2. Open the project folder.

3. Double-click:

```text
run_windows.bat
```

The application will start automatically.

4. Open in your browser:

```text
http://127.0.0.1:5000
```




## 📁 Structure

```text
app/          → Flask application
classification/ → AI classification
extraction/   → Data extraction
validation/   → Email validation
outreach/     → Gmail sending
search/       → Buyer discovery
templates/    → Web UI
data/         → CSV data
```
